# export.js

High-resolution exports of each plot (MS-23): `XP` (the plots, their boxes and file names), `xSize`, `svgFile` (a plot's SVG as a standalone file), `svgRaster`, `rangePixels` (a range plot's pixel layer redrawn at a scale), `curveSVG` (each 1-D plot's curves as vector paths, from the same traces as the screen: `tracesSVG` in `plot1d.js`), `ringExport` (the ring at any grid size), `exportPNG`, `exportSVG` and `exportMP4` (one sweep: d stepped from −range to +range over the pass time at 30 fps, each frame an `exportPNG`; d is put back afterwards; `prog(i, n)` is called after each frame with frames done and frames in all).

## Rules and pitfalls

- Never scale a rendered image up: an export is computed again at its own size with the same exact formulas. The range plots are redrawn with `XDPR` = scale (`DPR()` in `physics.js`) in one synchronous call and redrawn again at the device scale straight after, so the screen never shows the export. The ring is a fresh grid of exact footprint averages (`gridPix`, sd `PIXSD` of the export's own pixel) on a worker pool of its own, terminated afterwards, so it never touches the live renderer.
- `ringExport` colours pixels with `xyzRGB` and `ringGain`, the CPU paths' own colour code, and makes the outside of the circle transparent (anti-aliased over one pixel). The ring is capped at `XMAX` = 4096². It takes `stop()` to cancel (the menu closing).
- An SVG file sees none of the page's CSS: `svgFile` inlines the computed presentation styles of every element (colours are CSS variables such as `light-dark()`), removes classes and style attributes, and adds the panel colour behind. Add any new presentation property used by the plot SVGs to `XPROPS`.
- Every 1-D plot has a canvas layer (`cv`) and a `redraw`; its SVG export puts its traces under the axes as vector paths (`curveSVG`; the spectra through `XP[k].vec`). The interferogram's is the true curve ½(1 + Re γ(δ)), sampled at 16 points per fringe (`fringeN`, 2,000 to 400,000), stroked with a `linearGradient` of the perceived colour `hueOf(xyzAt(δ, 0))` along δ (256 to 20,000 stops, 8 per fringe). The interfered spectrum's adds its fill (the exact footprint average). The display's traces are pixel images with no vector form; the curves are what they draw.
- The PNG of a canvas plot is its redrawn pixel layer with the SVG drawn over it at the same scale (the SVG's own background is dropped there).
- The Exported plots check (`exportCheck`, in `ui-copy.js`) compares a device-scale export of every 1-D plot (both spectra, interferogram, profile) with its displayed canvas, tolerance 0; the Exported ring check compares `ringExport(160)` with `ringBrute`.
